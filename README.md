## About The Project

<!-- Placeholder for a screenshot or demo GIF -->
<!-- [![Product Name Screen Shot][product-screenshot]](https://example.com) -->

This project is a terminal-based implementation of the traditional Hangman word-guessing game. It is designed to be lightweight, modular, and easy to run on any system supporting Python. 

The primary objective of this repository is to demonstrate clean control flow, state management, and user input validation in a standard command-line interface environment. 

### Key Features
* **Dynamic Word Pool:** Words are randomly generated from an internal vocabulary list, ensuring high replayability.
* **State Management:** Real-time terminal updates tracking guessed characters, remaining lives, and the ASCII visual progression of the hangman.
* **Input Sanitization:** Built-in safeguards against invalid keystrokes, duplicate entries, and non-alphabetical characters to prevent runtime crashes.
